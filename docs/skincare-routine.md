# 保養流程與週期規劃 (Skincare Routine & Cycle Planning)

> 基準：混合偏中性肌，T 區易出油，屏障穩定。
> B5、Q10 為條件性使用（非每日必擦）。
> 參照產品清單：`./skincare-list.md`

---

## 每日基礎流程

### 早上 AM

**居家日**
```
1. m̄enom̄eno Sr 集水精華
2. TO 多胜肽眼精華
```

**出門日**
```
1. m̄enom̄eno Sr 集水精華
2. TO 多胜肽眼精華
3. IRITA Q10 水凝膜（薄擦）
→ BOJ 防曬棒
```

### 晚上 PM（基礎）

```
潔膚：Fc 洗面乳（+ Medicube Pad 視情況加）
1. IRITA 保濕修護精萃
2. TO 多胜肽眼精華 或 BOJ A 醛眼霜（輪替）
3. IRITA B5 精華乳（泛紅、乾癢、活性日後加）
```

> Medicube Pad 使用條件：出門日、T 區明顯出油、或無其他去角質產品的平穩日。
> Stridex 夜、Arencia 夜當天已有去角質，不加 Medicube Pad。

### 活性日 PM 結構

| 類型 | PM 步驟 |
|---|---|
| A 醇夜 | IRITA 精萃 → A 醇 → B5 → Q10 |
| Stridex 夜 | Stridex（T 區）→ IRITA 精萃 → B5 → Q10 |
| BOJ A 醛夜 | IRITA 精萃 → BOJ A 醛眼霜 → B5（可選）|

> 活性日 B5 必加。A 醇夜禁用美容儀、禁與 BOJ A 醛同夜。

## 週期規劃

### 月經期（Day 1–5）｜零刺激

**AM**：m̄enom̄eno Sr → TO 眼精華 →（Q10 出門日）

**PM**
```
潔膚：Fc 洗面乳（+ Medicube Pad 若 T 區出油）
1. IRITA 保濕修護精萃
2. TO 多胜肽眼精華
3. B5（有泛紅乾癢時加）
```

**面膜**：IRITA 面膜，每 3 天一次

**全停**：Stridex、A 醇、BOJ A 醛、Arencia、BOJ 米飯面膜、美容儀

---

### 濾泡期（Day 6–13）｜活性視窗

**AM**：同基礎每日流程

**PM 活性週排程**

| 類型 | 潔膚 | PM 步驟 | 面膜／儀器 |
|---|---|---|---|
| Stridex 夜（1–2 次）| Fc 洗面乳 | Stridex T 區 → IRITA 精萃 → B5 → Q10 | 禁儀器 |
| A 醇夜（1–2 次）| Fc 洗面乳 | IRITA 精萃 → A 醇 → B5 → Q10 | 禁儀器 |
| BOJ A 醛夜（最多 2 次）| Fc 洗面乳 | IRITA 精萃 → BOJ A 醛眼霜 → B5（可選）| 可搭 BOJ 米飯面膜 |
| Arencia 夜（1 次）| Arencia | IRITA 精萃 → TO 眼精華 | 可搭 Torriden 面膜 |
| 儀器夜（2–3 次）| Fc 洗面乳（+ Medicube Pad 若出油）| IRITA 精萃 → TO 眼精華 | 導入或提拉模式 |

**衝突規則**
- Stridex 日：禁 Arencia、禁 BOJ 米飯面膜、禁 Torriden 面膜
- A 醇夜：禁 BOJ A 醛、禁美容儀
- Arencia 日：禁 Stridex、禁 A 醇

---

### 排卵期（Day 14）｜延續濾泡期

AM／PM 結構同濾泡期。

**額外注意**
- Stridex 可用，當天禁 Torriden 面膜
- 美容儀效果最佳，優先安排提拉模式

---

### 黃體期前半（Day 15–21）｜降刺激過渡

**AM**：同基礎每日流程

**PM**
```
潔膚：Fc 洗面乳（+ Medicube Pad 若 T 區出油）
1. IRITA 保濕修護精萃
2. TO 眼精華 或 BOJ A 醛眼霜
3. B5（建議常備）
```

**活性調整**
- Stridex：全停
- A 醇：降為每週 1 次
- BOJ A 醛：維持，每週最多 2 次
- Arencia：每週 1 次（T 區控油替代 Stridex）
- BOJ 米飯面膜：每週 1 次，不與 Arencia 同天

---

### 黃體期後半（Day 22–28）｜全面修護

**AM**：同基礎每日流程

**PM**
```
潔膚：Fc 洗面乳（+ Medicube Pad 若 T 區出油）
1. IRITA 保濕修護精萃
2. TO 多胜肽眼精華
3. B5
```

**面膜**：IRITA 面膜，每 3 天一次

**全停**：Stridex、A 醇、Arencia、BOJ 米飯面膜、美容儀、BOJ A 醛（Day 26 起）
